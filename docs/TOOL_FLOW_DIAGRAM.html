Chart workflow and QC interpretation

This page follows the operator path from creating a control chart, to manual multi-level QC entry, to reading sigma bands and Bayesian next-value risk without guessing what the numbers mean.

Operator plus technical view

End-user workflow

1. Create chart stream

Pick analyte, method, instrument, site, QC level, units, target value, sigma, warning SD, action SD, and control lot.

2. Add prior

Set the Bayesian prior for the stream so the app has a starting belief about expected mean and spread.

3. Enter manual QC

The ingestion page preloads recent context, shows target/sigma/warning/action limits, and posts each level through /qc/records.

4. Read result

The response shows duplicate state, rule signals, Bayesian risk, disposition, and any alert created for the record.

5. Use the chart

Review result points, sigma bands, risk chart, alerts, events, exclusions, lot changes, and audit evidence.

What sigma means

Sigma is normal process spread.

If target is 5.2 and sigma is 0.25, then one sigma is 0.25 result units away from target.

limit = target +/- SD x sigma
-3 to +3 SD
On the result chart, green is close to target, amber is warning territory, and red is action territory.

How to read bands

+/- 1 SD

Ordinary variation around target. One point here is usually not interesting by itself.

+/- warning SD

Usually 2 SD. This is early warning territory and may combine with Westgard-style pattern rules.

+/- action SD

Usually 3 SD. This is action territory because the result is far from the expected in-control spread.

Bayesian next value

It is not a single predicted result.

The app updates its posterior from prior plus accepted QC history, then estimates the probability that the next result will land outside warning or action limits.

risk score = P(next value outside action limits) x 100
High Bayesian risk means the process may be drifting even before the newest point crosses a hard sigma line.

Operator reading sequence

Start with position.

Is the newest result near target, in warning territory, or past action limits?

Then check pattern.

A point inside limits can still matter if it contributes to repeated-side or spread rules.

Then check Bayesian risk.

If P(next outside action) is climbing, the process may need review before the next hard failure.

What not to overread

Sigma bands are configured expectations.

Bad target or sigma setup makes chart interpretation weak, even if the math runs.

Bayesian risk is conditional.

It depends on prior, included records, effective stream config, and control-lot history.

Risk is not a final verdict by itself.

Use it with rule signals, instrument context, audit events, and supervisor review.
